# Documentation Resources

This directory provides orientation around the research and code without
replacing the primary papers.

| Resource | Purpose |
|---|---|
| [`repository-map.md`](repository-map.md) | Maps each directory and artifact type |
| [`glossary.md`](glossary.md) | Defines recurring working terms |
| [`model-boundaries.md`](model-boundaries.md) | Separates theory, implementation, and evidence |
| [`reproducibility.md`](reproducibility.md) | Gives canonical commands and output expectations |

When a summary conflicts with a primary paper, the primary paper is the
authoritative source for that paper's claims and definitions.
