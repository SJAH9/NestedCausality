# Repository Map

## Continuum Game Theory

The [`Continuum Game Theory/`](../Continuum%20Game%20Theory/) directory contains
the current formal and computational work connecting Nested Causal Modelling
with game theory.

Each construction generally has three layers:

- a Markdown research text or formal definition;
- a Python implementation;
- a deterministic JSON reference result.

The paper PDF is retained beside its Markdown source for direct reading and
citation. The directory README provides the exact relationships among files.

## Instruments

The [`instruments/`](../instruments/) directory contains self-contained browser
tools. They are exploratory interfaces, not measurement devices and not
empirical evidence. Open an HTML file locally in a modern browser; no server or
build step is required.

## Documentation

The [`docs/`](./) directory supplies cross-cutting orientation, terminology,
model boundaries, and reproduction instructions. It should remain concise and
defer to primary research texts for complete arguments.

## Tools

The [`tools/`](../tools/) directory contains repository maintenance and
validation utilities. It must not contain unpublished research or alter source
papers during verification.
