Continuum Manifold Lab

An instrument for exploring geometries and the conditions that organize them. Begin with Facet Lab. Save a configuration to give it an address on the menu.

Each numerical address names symmetry, facets per step, rule, branching, facets per item and Bucky influence. Its saved preview count restores the occupied geometry. Saving the same configuration updates that address.

The menu has no preset address-count ceiling. It expands using the original Arcade subdivision rules. Browser memory and storage remain finite. Addresses are saved in this browser; export them to carry them elsewhere.

This original form preserves the executable Facet Lab. Connecting its configurations to a physical model and determining our universe remain research work.

Runs from a static folder, without an account, server, build step or network dependency. Requires a browser with WebGL 2.
